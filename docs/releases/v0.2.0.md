# InvestIQ v0.2.0 — Connected research and rights-aware decision history

**Release notes prepared for source release readiness.** Adding this file and changing the Python package version alone **does not publish** a GitHub release; a separate, approved `.release/v0.2.0.json` manifest controls the existing publication workflow.

## Added

- Venue-qualified issuer/listing/quote contracts, explicit market timestamp/session/timeliness/freshness and default-deny reuse permission metadata.
- SEC EDGAR recent filing metadata and Companyfacts US-GAAP annual metric adapters (selected 10-K and amended 10-K facts), with contact User-Agent, bounded fair-access pacing, exact Decimal values and provenance.
- Twelve Data BYOK one-minute candle CLOSE adapter; no falsely claimed exchange-level real-time classification. Plan-specific and exchange data rights remain the user's responsibility.
- Current connected issuer view with positive-earnings annual P/E proxy, currency/period/source guardrails and optional explicitly supplied valuation scenarios via Python.
- Private explicit research-decision snapshots, immutable thesis ancestry, create-only local files, offline method-versioned replay, JSON/Markdown exports. Quote values are **excluded** without express source retention permission.
- New `investiq research` and `investiq replay` commands, installed-CLI checks, end-to-end synthetic SEC/Twelve Data adapter and save/replay acceptance tests.
- Developer-focused draft-to-ready CI optimizations, sanitized transport errors, bounded retry policy and security/licensing-aware documentation.

## Compatibility

- Python 3.11+ and no mandatory external SDK or hosted services.
- Existing `investiq demo`, `investiq validate` and v0.1 synthetic JSON bundle continue to work.
- Snapshot method `connected-annual-pe-v1` and schema 1 are intentionally strict; no silent historical methodology migration.
- New commands require explicit issuer-to-listing metadata. `research` is network-enabled only with user-held environment credentials; `replay` is fully offline.
- The package version is `0.2.0` (not automatically published to a package index).

## Material limitations

This is experimental analyst tooling, **not** investment advice, a live licensed market-data terminal, a stock screener, a brokerage or a historical backtesting product. No automated CI run uses live provider keys. SEC filing dates do not establish intraday public release, the supported annual metric set is narrow, and the Twelve Data adapter declares both quote timeliness and snapshot retention permissions UNKNOWN until verified. Private stored decisions therefore may omit price and price-based valuation. Hashes are not external timestamps or signatures.
