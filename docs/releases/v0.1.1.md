# InvestIQ v0.1.1 — Provenance and release-integrity maintenance

This patch release retains the fully offline, open-source InvestIQ 0.1 research toolkit and corrects two problems detected during final review of v0.1.0.

## Fixes
- The valuation workflow now checks supporting evidence for a selected growth hypothesis even if it is not cited by the accompanying report or thesis. Missing IDs, unrelated securities and future/late-recorded evidence are rejected.
- GitHub release automation confirms that any pre-existing version tag points to exactly the source commit that passed validation before uploading build artifacts.

## Included in the v0.1 line
Portable evidence and hypothesis contracts, valuation scenarios, five reusable research skills, immutable thesis history, an offline `investiq demo` and `investiq validate` CLI, reproducible Python distribution builds and an MIT license.

## Install
Download `investiq_core-0.1.1-py3-none-any.whl` from this release and install with:

```bash
python -m pip install investiq_core-0.1.1-py3-none-any.whl
investiq demo --output synthetic.json
investiq validate synthetic.json --basis recorded
```

## Limitations
No live market data, hosted web app, brokerage execution, stock recommendation, quantitative backtest or proven investment performance. The demonstration is entirely synthetic; validation is structural rather than a semantic fact-check. Investing involves risk.
