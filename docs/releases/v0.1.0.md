# InvestIQ v0.1.0 — Open-source research toolkit

This is the first release of InvestIQ: a **fully offline, model-agnostic, open-source Python toolkit** for reproducible equity research.

## Included
- Attributed observation and hypothesis contracts with historical source dates.
- Deterministic growth, forward P/E, reverse-valuation and sensitivity calculations.
- Five portable research skills and a common citation-aware research-report format.
- Hash-linked thesis history with time-aware validation and JSONL import/export.
- An installable `investiq` CLI that generates and validates an end-to-end fictional example.
- MIT license, contribution/security guidance, tests, build and release documentation.

## Try it

```bash
python -m pip install investiq_core-0.1.0-py3-none-any.whl
investiq demo --output synthetic.json
investiq validate synthetic.json --basis recorded
```

Download an attached wheel or build from source. All demonstration data is fictional.

## Not included
Live data, a hosted application, personal advisory services, quantitative fund management, trading, portfolio records, point-in-time backtesting, empirically proven strategy returns or any promise of investment performance.

## Safety
Financial estimates and hypotheses must be checked independently. Structural validation does not fact-check research prose. The hypothetical price-only scenarios omit dividends, dilution, costs and other risks. The project is not investment advice.
