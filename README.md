# InvestIQ

**Open-source investment research infrastructure.**

InvestIQ aims to provide reproducible, evidence-based tools for fundamental equity research, valuation, investment thesis tracking, and systematic strategy research.

The project is intended for anyone: individual researchers, students, developers, and open-source contributors. It is not a personalized portfolio, investment advisory service, brokerage, or managed fund.

> **Status:** Early-stage community project. APIs, methodology, and examples are under development. Do not use outputs as trading instructions.

## Principles
- **Reproducibility:** explicit formulas, tests, assumptions, and versioned methods.
- **Evidence first:** distinguish reported facts, third-party estimates, and hypotheses.
- **Point-in-time integrity:** avoid look-ahead bias and preserve source timestamps.
- **Uncertainty:** mark missing data and limitations rather than inventing numbers.
- **Modularity:** useful as a Python library before adding applications or services.
- **Privacy:** no personal account, transaction, or portfolio data in the repository.

## Roadmap
1. Methodology and public project governance.
2. Tested financial calculation and valuation core.
3. Portable research skills and evidence schemas.
4. Research records and thesis-change history.
5. Backtesting and paper portfolios, with credible out-of-sample evaluation.
6. Optional user interfaces and integrations.

See the forthcoming foundation pull request for the detailed architecture and contribution guidance.

## Investment-risk notice
InvestIQ is research software for educational and informational use. It does not provide individualized investment advice. All investing involves risk, including loss of principal. Model results depend on data quality and assumptions.
